# Sign Up Form — The Odin Project

## Description

This project is asign up form built as part of The Odin Project curriculum. It focuses on practicing HTML forms, CSS styling, layout techniques, and basic client-side validation.

The goal is to create a clean, accessible, and user-friendly registration interface.

## Live Preview
https://liambamufaya.github.io/Sign-up-form/


## Features

* Structured HTML form with semantic elements
* Custom styling with CSS
* Required field validation
* Password and confirm password fields
* Focus and hover states for inputs
* Accessible labels

## Form Fields

* First Name
* Last Name
* Email Address
* Phone Number
* Password
* Confirm Password

## Technologies Used

* HTML5
* CSS3

## What I Learned

* How to structure forms using labels and inputs
* Using Flexbox for layout
* Styling form controls consistently
* Basic form validation techniques
* Improving accessibility with proper labeling

## Future Improvements

* Add JavaScript validation feedback
* Show password strength indicator
* Backend integration for real signups
* Error messages and success states
* Mobile UX refinements

## How to Run Locally

1. Clone the repository
2. Open `index.html` in your browser
